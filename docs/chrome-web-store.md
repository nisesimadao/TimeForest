# Chrome Web Store 提出メモ（下書き）

提出には Google の開発者アカウント（登録料 $5・一度きり）と審査が必要です。
以下はそのまま貼れる掲載文と、審査で聞かれる項目の下書きです。

## アップロードするもの

`timeforest-extension.zip`（`manifest.json` + `src/` + `icons/`）。
リリースの成果物、または手元で:

```bash
zip -r timeforest-extension.zip manifest.json src icons
```

manifest は MV3、アイコンは 16/32/128 を同梱済み。

## 掲載情報

- **名前**: TimeForest
- **カテゴリ**: 仕事効率化（Productivity）
- **言語**: 日本語（英語 UI にも自動対応）
- **単一の目的（Single purpose）**:
  > TimeTree のウェブ版に、公式には無いアジェンダ表示・エクスポート・ダークモード・
  > 地図ピン・アカウント切替・リマインド通知を、同じ画面の中に足す。

### 短い説明（132 文字以内）

> TimeTree のウェブ版に、アジェンダ表示・エクスポート(MD/CSV/JSON/ICS)・ダーク
> モード・地図ピン・アカウント切替・通知を、本家 UI に溶け込む形で足す非公式拡張。

### 詳しい説明

> TimeForest は TimeTree の**非公式**クライアントです。本家のウェブ版に、公式には
> 無い機能を「もとからあったボタン」のように足します。
>
> - **アジェンダ表示** — マンスリー/ウィークリー切替に第3のビュー。予定をクリックで
>   詳細（場所・参加者・作成者・メモ）を表示し、「本家で編集」で本家のネイティブ
>   編集画面をそのまま開く。
> - **エクスポート** — 今月の予定を Markdown / CSV / JSON / ICS で書き出し。
> - **ダークモード** — 本家が内蔵しつつ露出していない純正ダークテーマを切り替え。
> - **地図ピン** — 予定フォームに地図から場所を選ぶ行（本家ウェブに無い）。
> - **アカウント切替** — 複数アカウントをパスワード無しで切替（本家ウェブに無い）。
> - **リマインド通知** — Chrome 起動中に OS 通知で知らせる。
>
> あなた自身のアカウントのデータを端末内だけで扱い、作者のサーバーには何も送りません。
> 詳細はプライバシーポリシー参照。オープンソース（MIT）。

- **プライバシーポリシー URL**: 公開後の `PRIVACY.md`（例:
  `https://github.com/nisesimadao/TimeForest/blob/main/PRIVACY.md`）

## 権限の正当化（審査フォーム用）

| 項目 | 記入内容 |
| --- | --- |
| `cookies` | アカウント切替のため timetreeapp.com のセッションクッキーを Service Worker で読み書きする。 |
| `storage` | 設定・アカウント一覧・通知状態・予定キャッシュを端末内に保存する。 |
| `tabs` | 開いている timetreeapp.com タブへ設定を反映し再読み込みする。通知クリックで該当タブを前面化する。 |
| `alarms` | リマインド通知を1分間隔で点検する。 |
| `notifications` | リマインドを OS 通知として表示する。 |
| `declarativeNetRequest` | 拡張自身の書き込みリクエストの Origin/Referer を timetreeapp.com に整える（対象ドメイン＋xmlhttprequest に限定）。 |
| ホスト権限 `timetreeapp.com` | 本体の UI に機能を注入し、認証付き API を呼ぶ。 |
| ホスト権限 `*.openstreetmap.org` / `nominatim.openstreetmap.org` | 地図機能 ON 時にタイル取得と場所検索を行う。 |
| リモートコード | 使用しない（すべて同梱の同一オリジンコード）。 |

## データ利用の申告（Privacy practices）

- 収集する個人情報: **なし**（作者のサーバーは存在しない）。
- 第三者への販売・移転: **なし**。
- 用途外利用: **なし**。
- 「単一目的」に合致、リモートコード無し、と申告。

## 用意するアセット

- アイコン 128px（同梱: `icons/icon-128.png`）。
- スクリーンショット 1280×800 または 640×400 を最低1枚（`docs/shots/` の画像を
  この比率に整えて使う。実データが写らないものを選ぶこと）。
- 小さなプロモタイル 440×280（任意）。
